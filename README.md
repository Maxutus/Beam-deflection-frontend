# Расчёт прогиба балки — фронтенд

Учебный проект по курсу «Разработка интернет-приложений».

## Задание

Расчет прогиба балки. `Услуги` - типы балок (деревянные, металлические,
железобетонные) с модулями упругости материалов. `Заявка` - расчет величины
прогиба балки указанной длины под действием указанной нагрузки и проверка его
на соответствие нормам.

## Стек

- React, Redux
