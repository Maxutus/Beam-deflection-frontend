# Расчёт прогиба балки – фронтенд

Учебный проект по курсу «Разработка Интернет-Приложений (РИП)» Кафедра ИУ5, МГТУ им. Н.Э. Баумана, 2026

**Тема:** Расчёт прогиба балки **Группа:** ИУ5-55Б

Бэкенд: [Beam-deflection-backend](https://github.com/Maxutus/Beam-deflection-backend)

## Предметная область

Веб-сервис для подбора типа балки и проверки её прогиба на соответствие нормам.

**Услуги** – типы балок (деревянные, металлические, железобетонные) с модулями упругости материалов.

**Заявка** – расчёт величины прогиба балки указанной длины под действием указанной нагрузки и проверка его на соответствие нормам.

## Стек

- React, TypeScript, Vite
- React Router, React-Bootstrap
