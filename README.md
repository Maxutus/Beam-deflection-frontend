# Расчёт прогиба балки – фронтенд

Учебный проект по курсу «Разработка интернет-приложений», ИУ5-55Б.

Лабораторная работа 5: SPA на React + TypeScript для гостя. Данные берутся только из mock-объектов, к бэкенду приложение не обращается.

## Задание

Расчёт прогиба балки. `Услуги` – балки (деревянные, металлические, железобетонные) с фото, видео, нагрузкой и прогибом. `Заявка` – черновик новой балки, который пользователь заполняет и публикует в ленту.

## Стек

- React 19, TypeScript, Vite
- React Router (`react-router-dom`)
- React-Bootstrap (`Navbar`, `Nav`, `Card`, `Form`, `Button`)

## Страницы

### Плитка – `/beams`

Список балок плиткой в две колонки. С адреса `/` происходит переход сюда.

| Элемент | Что делает |
|---|---|
| Поле «Прогиб до, мм» | Максимальный прогиб для фильтра. Принимает дробные числа, через точку или запятую |
| Кнопка «Найти» (или Enter) | Оставляет балки с прогибом не больше введённого. Пустое поле – показываются все балки |
| «Найдено балок: N» | Сколько балок сейчас показано |
| Карточка балки | Фото, прогиб в мм, название, число лайков. Клик открывает эту балку в ленте |

Если ни одна балка не подошла, выводится сообщение «Балок не найдено».

### Лента – `/beams/feed` и `/beams/feed/:id`

Одна балка на весь экран, как в коротких видео. Без `id` открывается первая балка, с `id` – балка с этим номером.

| Элемент | Что делает |
|---|---|
| Видео | Проигрывается автоматически, без звука, по кругу. Пока грузится – показывается фото балки |
| Название, «Прогиб», «Нагрузка» | Параметры балки: прогиб в мм, нагрузка в кН/м |
| Описание и кнопка «больше / меньше» | Описание свёрнуто до двух строк, кнопка разворачивает и сворачивает его |
| Жёлтая кнопка с сердцем | Число лайков. Для гостя только показывает количество |
| Кнопка со стрелкой | Переход к следующей балке. После последней – снова первая |

Если балки с таким `id` нет, выводится «Балка не найдена» и кнопка «К списку балок».

### Добавление – `/beams/draft`

Заготовка страницы черновика (открывается только по прямому адресу, в навбаре пункт выключен).

| Поле | Что вводится |
|---|---|
| Изображение | Фото балки. Файл выбирается нажатием на квадрат, после выбора показывается его превью, до выбора – заглушка |
| Видео | Видео балки. Файл выбирается нажатием на квадрат, после выбора показывается его превью, до выбора – заглушка |
| Название | Название балки |
| Описание | Текст о том, как балка ведёт себя под нагрузкой |
| Нагрузка, кН/м | Нагрузка на балку |
| Прогиб, мм | Прогиб балки |

Кнопка «Опубликовать» пока выключена – публикация появится вместе с авторизацией и бэкендом.

### Несуществующий адрес

Сообщение «Страница не найдена» и кнопка «К списку балок».

## Навбар

| Пункт | Состояние |
|---|---|
| Лента | Включён, ведёт на `/beams/feed` |
| Добавление | Выключен (для гостя недоступен) |
| Плитка | Включён, ведёт на `/beams` |
| Вход | Выключен (авторизация в следующих лабораторных) |

Активный пункт выделяется жирным.

## Данные и медиа по умолчанию

- Mock-данные – `src/modules/mock.ts`: пять балок из `seed.sql` бэкенда с теми же полями, что в ответе API (`id`, `name`, `description`, `image_url`, `video_url`, `load`, `deflection`, `like_count`, …).
- Если у балки пустое поле `image_url` или картинка не загрузилась, показывается `public/DefaultImage.png`.
- Если пустое поле `video_url` или видео не загрузилось, показывается `public/DefaultVideo.mp4`.
- Фото и видео балок лежат в `public` рядом с медиа по умолчанию. У балки «Брус строганый» в mock пустое поле `video_url`, у «Плита ПК 60-15» – оба поля, чтобы было видно подстановку по умолчанию.

## Структура

```
src/
  Routes.tsx            адреса страниц и подписи навбара
  App.tsx               роутер, список балок в useState, передача через props
  components/
    TabBar.tsx          навбар
    InputField.tsx      поле фильтра с кнопкой
    BeamCard.tsx        карточка балки
  modules/
    beamsApi.ts         тип Beam, пути медиа по умолчанию
    mock.ts             mock-данные
  pages/
    TilesPage.tsx       плитка
    FeedPage.tsx        лента
    DraftPage.tsx       добавление
    NotFoundPage.tsx    404
```

Данные передаются сверху вниз через props: `App` → страницы → `BeamCard`. Redux и Context не используются.

Хуки: `useState` (список балок, фильтр, состояние описания и формы), `useEffect` (mock в отображаемый список при открытии плитки, сброс описания и видео при переходе к другой балке, заголовок вкладки, превью файлов с очисткой), `useParams` (`id` балки в ленте), `useNavigate` (переходы по кнопкам), `useLocation` (активный пункт навбара).
